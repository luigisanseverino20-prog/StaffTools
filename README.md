# StaffTools

Minecraft staff moderation plugin with warn system, auto-ban and permission management.

## Features
- /warn <player> <category> <reason> — warn a player
- /warnlist <player> — view all warns for a player
- /clearwarns <player> — reset all warns for a player
- Auto-ban after reaching warn limit per category
- Data saved persistently in warns.yml
- Fully configurable warn limits per category

## Categories
- insulto — 3 warns = auto-ban
- cheat — 3 warns = auto-ban
- spam — 3 warns = auto-ban
- avviso — notification only, no ban

## Compatibility
- Paper 1.21 / 1.21.1
- Java 21+

## Installation
1. Download the .jar file
2. Place it in your server's /plugins folder
3. Restart the server
